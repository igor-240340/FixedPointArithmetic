// Как преобразовать числовую строку в формат бинарной фиксированной точки минуя конвертацию в float.
// Сначала читаем ASCII-цифры и формируем int как в atoi (запоминая overscale по десятичной точке).
// В данном примере overscale=10^3=1000.
225.125: num
225125: num*1000
225000: int(num/1000)*1000
125: 225125-225000=frac*1000
32000: frac*1000*2^8 // сдвигаем на 8 разрядов влево.
32: 32000/1000=(frac*1000*2^8)/1000=frac*2^8 // 8 двоичных разрядов истинной дробной части.
bin(32)=00100000 // индексы от [-1,-8] => 2^-3=0.125, а это и есть истинная дробная часть.
